# Package index

## Retrieve Census data

Product-specific wrappers for Census data products.

- [`tc_get_acs()`](https://christophertkenny.com/tinycensus/reference/tc_get_acs.md)
  : Retrieve American Community Survey data
- [`tc_get_decennial()`](https://christophertkenny.com/tinycensus/reference/tc_get_decennial.md)
  : Retrieve Decennial Census data
- [`tc_get_pep()`](https://christophertkenny.com/tinycensus/reference/tc_get_pep.md)
  : Retrieve Population Estimates Program data
- [`tc_get_pdb()`](https://christophertkenny.com/tinycensus/reference/tc_get_pdb.md)
  : Retrieve Census Planning Database data
- [`tc_get_cbp()`](https://christophertkenny.com/tinycensus/reference/tc_get_cbp.md)
  : Retrieve County Business Patterns data
- [`tc_get_flows()`](https://christophertkenny.com/tinycensus/reference/tc_get_flows.md)
  : Retrieve ACS migration flows
- [`tc_get_timeseries()`](https://christophertkenny.com/tinycensus/reference/tc_get_timeseries.md)
  : Retrieve Census time-series data

## Explore metadata

Helpers for discovering datasets, variables, tables, geographies, and
examples.

- [`tc_datasets()`](https://christophertkenny.com/tinycensus/reference/tc_datasets.md)
  : List Census datasets from the discovery catalog
- [`tc_dataset()`](https://christophertkenny.com/tinycensus/reference/tc_dataset.md)
  : Retrieve a single Census dataset record
- [`tc_variables()`](https://christophertkenny.com/tinycensus/reference/tc_variables.md)
  : Retrieve Census variable metadata
- [`tc_tables()`](https://christophertkenny.com/tinycensus/reference/tc_tables.md)
  : Retrieve Census table metadata
- [`tc_table_variables()`](https://christophertkenny.com/tinycensus/reference/tc_table_variables.md)
  : Retrieve variables for a Census table
- [`tc_groups()`](https://christophertkenny.com/tinycensus/reference/tc_groups.md)
  : Retrieve raw Census group metadata
- [`tc_geography()`](https://christophertkenny.com/tinycensus/reference/tc_geography.md)
  : Retrieve Census geography metadata
- [`tc_examples()`](https://christophertkenny.com/tinycensus/reference/tc_examples.md)
  : Retrieve Census example query metadata
- [`tc_search_variables()`](https://christophertkenny.com/tinycensus/reference/tc_search_variables.md)
  : Search Census variable metadata
- [`tc_values()`](https://christophertkenny.com/tinycensus/reference/tc_values.md)
  : Retrieve encoded values metadata for a Census variable

- [`tc_get_key()`](https://christophertkenny.com/tinycensus/reference/tc_get_key.md)

- [`tc_has_key()`](https://christophertkenny.com/tinycensus/reference/tc_has_key.md)
